### How to use this project:
1. Use Apache NetBeans IDE 20
2. Download the file.
3. Create new project: Category:[Java with Ant], Projects:[Java Application]. You can choose any name for the project 
4. Paste File under the projectName\Source Packages.
5. To use the generator, run the Main.java File
